# 君行越韵 · 陈丽君艺术档案 V2.0.0

面向中国大陆网络环境设计的非官方越剧艺术档案与五层全域资讯中心。

## 核心能力
- 官方与本人、权威媒体、演出与节目、视频平台、戏迷社区五层资讯引擎
- 每日两次 GitHub Actions 自动巡检
- Cloudflare Pages Functions 同源实时接口 `/api/news`
- 今日丽君日报、来源健康诊断、分类搜索与本机收藏
- 20 张在线影像、主流平台互动观察、动态、小考、签到、云笺、分享卡、PWA 离线访问

## 部署
完整上传所有文件和隐藏目录，尤其是 `.github/`、`functions/`、`scripts/`、`data/`。GitHub Actions 需启用 Read and write permissions。

## 说明
系统保证每日自动巡检，不保证演员每天必然产生新事件。重要信息请打开原文核验。正式商业使用前需处理肖像、剧照、媒体摘要及院团名称授权。
