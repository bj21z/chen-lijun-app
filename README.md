# 君行越韵 · 陈丽君艺术档案 V1.0.0

面向 iPhone 的非官方越剧艺术档案与戏迷互动网页小程序。核心资源全部本地化，不依赖 Google、境外字体或境外 CDN。

## 运行
直接打开 `index.html` 可预览；完整动态同步与离线缓存建议部署到 GitHub Pages 或 Cloudflare Pages。

## 发布
请上传本目录全部文件，不要只上传 `index.html`。首次升级后建议关闭旧标签页再重新进入。

## 动态维护
编辑 `data/dynamics.json`，更新 `updatedAt`、`version` 和 `items` 后重新部署。
